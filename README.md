# 本地网页标记

一个将网页收藏、文字标记和笔记保存在当前 Chrome 浏览器中的扩展。无需账号，不会把标记内容上传到服务器；适用于普通 HTTP/HTTPS 网页。

## 主要功能

- 收藏网页，并从浏览器原生侧栏或独立管理页的“全部标记”跨页面搜索、打开记录。默认按网页分组，也可按网站分组或按时间查看，每组支持折叠。
- 选中文字添加书签、重点标注或笔记；重点标注支持高亮、直线下划线和波浪线。
- 选中文字后，悬停在“标注”上可直接选择高亮、直线或波浪线；悬停在已有标记的“修改”上，点击类型会立即切换原文效果；直接点击“修改”可进入颜色、粗细等详细编辑。
- 调整标记的颜色、覆盖程度或线条粗细、透明度时可实时预览，也可修改或删除已有标记。鼠标悬浮在标记上可打开操作菜单，悬浮在带笔记的原文上可预览笔记。
- 新建高亮默认红色、粗（铺满文字）、实色；直线和波浪线默认中等粗细。三种标注类型分别记住颜色、粗细和透明度，已有标记的细节编辑也会更新相应类型的偏好。
- “详细设置”中可清空所有网页的标记、笔记和网页收藏，执行前会显示数量并要求确认。样式和分组偏好保留。
- 重新打开网页时尝试恢复标记；可导出和导入 JSON 备份，迁移到另一安装版本。

## 本地安装

1. 在仓库根目录运行 `python3 -B package_release.py`，生成干净的开发者模式安装目录。
2. 打开 Chrome 的 `chrome://extensions/`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择 `dist/chrome-local-marks-unpacked`。请勿选择源码根目录，源码中可能含测试缓存等 Chrome 不接受的文件名。
4. 打开并刷新一个普通网页，网页侧边会显示标记图标入口；点击它或浏览器工具栏中的扩展图标可打开原生侧栏。需要 Chrome 142 或更新版本。

如需在 `file://` 本地文件中使用，还需在扩展详情页开启“允许访问文件网址”。

## 使用限制与数据

- Chrome 设置页、Chrome 网上应用店、新标签页等受保护页面无法使用扩展。
- 网页大幅改版或删除原文后，旧标记仍会保留，但可能无法自动定位到原处；动态网页的标记恢复也可能受网站重新渲染影响。
- 数据保存在当前 Chrome 配置文件的 `chrome.storage.local` 中。卸载扩展、清除扩展数据，或在不同扩展 ID 的安装版本之间迁移前，请先导出备份；导出的 JSON 含网址、原文和笔记，不宜公开分享。

扩展不使用远程服务或统计 SDK。完整的数据处理与权限说明见[隐私政策](https://ai-notes-ecru-three.vercel.app/chrome-local-marks-privacy.html)。

维护者的测试、打包和上架检查见 [RELEASING.md](RELEASING.md)。

## 0.5.0 交互调整

- 新建标注继续支持悬停二级选择；已有标注停留 300ms 预览笔记、700ms 显示编辑工具条，点击则立即显示。离开 250ms 后收起，使用 140ms 淡入淡出和轻位移；遵循系统“减少动态效果”。时间固定，不提供档位。
- 笔记摘要与操作合并在同一浮层中。滚动、Esc 或点击空白处可收起；类型和样式可快速修改，完整笔记与详情在侧栏编辑。
- 常驻入口可在详细设置中选择左侧、右侧或隐藏，不提供首次使用引导。
- 原生侧栏适应宽度与系统明暗，不继承网页样式。本页按正文顺序排列，全部记录支持网页／网站分组，另有独立管理页。
- 更新时在扩展管理页面重新加载现有安装目录，再刷新网页；不需要卸载。若改用不同安装路径，先导出备份。

## 0.5.1 悬停修正

- 正文停留 700ms 仅显示编辑工具条；笔记图标停留 300ms 显示独立笔记卡片，点击也可查看。笔记卡片保留段落、支持长笔记滚动。
- 同一标注的多行／多个文字片段共用悬停状态，跨行不重新播放笔记与编辑菜单。
- 样式面板脱离工具条布局，展开不移动触发按钮；留出 250ms 鼠标移动宽限。
- 侧栏顶部增加向外收起箭头。打开时隐藏网页入口，通过箭头或 Chrome 自带关闭按钮收起后恢复入口；用户设置的隐藏偏好仍保留。
- 为支持原生侧栏关闭事件，最低版本更新为 Chrome 142（本次本机为 154）。

## 0.5.2 菜单状态修正

- 一级功能悬停或获得焦点时，收起其他功能的二级菜单；类型和样式面板互斥。
- 恢复浅／深色主题下清晰的一级 hover、焦点、展开反馈，删除操作使用独立红色反馈。
- 新建菜单二级面板独立定位，展开不移动一级按钮。
- 离开宽限时间、Esc、隐藏面板的键盘可访问状态与展开属性保持一致。
- 异步保存后不会重新打开已经收起的样式面板。

## 0.5.3 笔记快捷输入

- 添加或编辑笔记直接使用快捷输入框，按 Enter、失焦或点击其他区域保存，Shift+Enter 换行。
- 笔记不再附带高亮、直线或波浪线，使用独立的柔和气泡标记。
- 笔记预览采用 70% 背景不透明度的半透明气泡，文字保持清晰。
- 新建标注二级菜单统一使用不透明底色，确保三个选项在网页背景上都可辨认。

## 0.5.4 笔记和入口位置修正

- 纯笔记悬停正文任意位置只显示笔记气泡，不再打开编辑菜单。
- 笔记气泡使用 70% 背景不透明度，呈现轻微透明效果。
- 侧栏收起箭头移动到侧边垂直中心，箭头方向跟随侧栏位置。
- 网页侧边“标注”入口支持上下拖动，并记住位置。

## 0.5.5 气泡和侧栏位置修正

- 笔记气泡整体使用 70% 不透明度，包含文字和内容层。
- 右侧侧栏的收起箭头放在靠网页的左缘；左侧侧栏则放在靠网页的右缘。

## 0.5.7 入口简化

- 网页侧边常驻入口只保留标记图标，移除“标注”文字和数量显示；保留无障碍名称与悬停提示。

## 0.5.6 侧栏收起轨道

- 侧栏内侧为收起箭头预留固定空间，箭头不再覆盖记录列表、搜索和设置内容。
