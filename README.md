# 本地网页标记

一个将网页收藏、文字标记和笔记保存在当前 Chrome 浏览器中的扩展。无需账号，不会把标记内容上传到服务器；适用于普通 HTTP/HTTPS 网页。

## 主要功能

- 收藏网页，并从扩展弹窗跨页面搜索、打开收藏和文字标记。
- 选中文字添加书签、重点标注或笔记；重点标注支持高亮、直线下划线和波浪线。
- 调整标记的颜色、覆盖程度或线条粗细、透明度，也可修改或删除已有标记。鼠标悬浮在标记上可打开操作菜单，悬浮在带笔记的原文上可预览笔记。
- 重新打开网页时尝试恢复标记；可导出和导入 JSON 备份，迁移到另一安装版本。

## 本地安装

1. 在仓库根目录运行 `python3 -B package_release.py`，将 `dist/` 中生成的 ZIP 解压到单独目录。
2. 打开 Chrome 的 `chrome://extensions/`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择解压后的目录。
4. 打开并刷新一个普通网页，右下角会显示标记入口；点击浏览器工具栏中的扩展图标可查看跨网页列表。

如需在 `file://` 本地文件中使用，还需在扩展详情页开启“允许访问文件网址”。

## 使用限制与数据

- Chrome 设置页、Chrome 网上应用店、新标签页等受保护页面无法使用扩展。
- 网页大幅改版或删除原文后，旧标记仍会保留，但可能无法自动定位到原处；动态网页的标记恢复也可能受网站重新渲染影响。
- 数据保存在当前 Chrome 配置文件的 `chrome.storage.local` 中。卸载扩展、清除扩展数据，或在不同扩展 ID 的安装版本之间迁移前，请先导出备份；导出的 JSON 含网址、原文和笔记，不宜公开分享。

扩展不使用远程服务或统计 SDK。完整的数据处理与权限说明见[隐私政策](https://ai-notes-ecru-three.vercel.app/chrome-local-marks-privacy.html)。
