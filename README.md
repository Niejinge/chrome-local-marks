# 本地网页标记（Chrome 扩展）

一个只使用 `chrome.storage.local` 的本地阅读标记工具，不上传网页内容，也不需要账号。它与 AI 学习笔记网站分别维护；插件可用于普通 HTTP/HTTPS 网页，并不依赖该网站。

当前版本：`0.4.0`

## 能做什么

- 收藏整个网页，并可在任意页面右下角面板的“网页收藏”中跨页面查看和打开。
- 选中文字后添加书签、标注或笔记；“标注”统一包含高亮、直线和波浪线三种形式。
- 书签使用醒目的左侧边标，与重点标注的文字底色明确区分；颜色和边标宽度都可以调整。
- 重点标注提供 9 种常用颜色、细/中/铺满预设，并可用滑杆连续调节覆盖程度；“铺满”会填满文字标记区域，并在行距允许时向上下扩展，避免字形顶部露出。
- 下划线支持直线和波浪线，颜色、粗细均可使用预设或连续调节。
- 书签、重点标注和下划线都支持“淡/中/实”透明度预设，也可在 10%～100% 之间连续调节。
- 选中文字后的快捷菜单只保留书签、标注、笔记三个主操作；颜色、粗细、透明度和标注形式集中在最右侧的统一设置入口。
- 右下角“我的标记”面板中的齿轮可统一设置新标记的默认样式。
- 在快捷菜单中更改形式、颜色、粗细或透明度后，会立即按新样式标记当前文字；菜单保持打开，可继续微调。
- 点击已有标记可选择“修改”，并即时调整其形式、颜色、粗细和透明度。
- 鼠标悬浮在已有标记上即可显示“修改 / 笔记 / 删除”快捷菜单；移到菜单时不会立即消失，点击和键盘聚焦仍可使用。
- 快捷菜单采用一体式表面，不再为每个操作增加独立卡片或下拉箭头；各级菜单使用统一的线性图标。
- 点击已标注文字，可查看、编辑笔记或删除。
- 含笔记的文字末尾会显示独立的笔记图标；鼠标悬浮在笔记原文上可直接预览笔记，长内容最多显示四行并自动省略；动态网页前后文发生小幅变化时，会结合相似上下文和原位置继续定位原文。
- 定位时把连续空格、换行和制表符视作等价，兼容论坛回复、代码托管和文档网站中“看起来相同、源码空白不同”的正文。
- 右下角入口查看当前网页的全部标记。
- 点击浏览器工具栏中的扩展图标，可跨网页搜索并跳回原文。
- 弹出窗口的“备份与迁移”可导出 JSON，并把旧安装中的标记合并导入；相同记录不会覆盖，样式恢复需主动勾选。

## 本地安装

1. 在 Chrome 地址栏打开 `chrome://extensions/`。
2. 打开右上角“开发者模式”。
3. 在本仓库运行 `python3 -B package_release.py`，解压 `dist/` 中生成的 ZIP 到一个单独目录。
4. 点击“加载已解压的扩展程序”，选择刚解压出的目录。
5. 打开一个普通网页并刷新，即可在右下角看到书签图标。

如需在 `file://` 本地文件中使用，请在扩展详情页开启“允许访问文件网址”。

## 使用边界

- Chrome 设置页、Chrome 网上应用店、新标签页等浏览器受保护页面不允许扩展注入脚本。
- 标记定位依赖原文、前后文和文本位置。网页大幅改版或原文被删除后，旧标记仍会保留在列表中，但可能无法自动跳回原位置。
- 高度动态的网页可能重新渲染正文；扩展会尝试恢复标记，但不会修改网站业务数据。
- 数据只存在当前 Chrome 配置文件中。卸载扩展或清除扩展数据前，请自行备份需要保留的内容。
- 手动安装版与商店版若使用不同扩展 ID，本地数据不会自动迁移。请在旧版先导出，再在新版导入；确认成功后再卸载旧版。
- 导出的 JSON 包含网址、原文和笔记，请不要将它公开分享。

## 隐私

- 无网络请求、无远程服务、无统计 SDK。
- 仅保存用户主动收藏的网址、网页标题、所选原文、前后少量定位文本和笔记。
- 权限用途：`storage` 用于本地保存；HTTP/HTTPS 网站访问权限用于显示标记、在重新打开网页后恢复标记，以及从列表跳回原文。`file://` 支持需要用户另外在扩展设置中开启。

## 发布准备

- 在仓库根目录运行 `python3 -B -m unittest test_chrome_local_marks.py` 和 `node test_chrome_backup.mjs`；再检查 JavaScript 语法，并在 Chrome 中安装发布包进行手动验收。
- 运行 `python3 -B package_release.py` 生成当前版本的商店上传包。它只打包运行时文件，`manifest.json` 位于 ZIP 根目录；测试、Git 文件和本地缓存不会进入包。ZIP 属于发布产物，不提交到源码仓库。
- 隐私政策由学习笔记网站仓库的 `chrome-local-marks-privacy.html` 提供，公开地址是 `https://ai-notes-ecru-three.vercel.app/chrome-local-marks-privacy.html`。修改数据处理方式时，需同步更新该页面和商店隐私声明。
