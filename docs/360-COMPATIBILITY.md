# 360 极速浏览器兼容预览

分支：`compat/360-chromium-132`。独立工作目录、安装目录与包名，保留 `main` 和 v0.7.4 Chrome 稳定版。兼容版最低 Chromium 132，应用版本 0.7.5，版本名称为 0.7.5-360-preview。

## 界面与权限

兼容包不申请 `sidePanel` 权限，点击网页入口或浏览器扩展按钮打开独立标记管理窗口。同一来源窗口重复打开会复用管理窗口；不同浏览器窗口各自保留详情上下文。管理窗口中的“本页”始终读取来源窗口当前网页，避免误读取自身扩展页面。打开窗口不会调整正文窗口大小。

关闭按钮先保存当前编辑，再关闭管理窗口。关闭来源窗口会清理对应的管理窗口；关闭管理窗口后可以从网页入口再次打开。后台通过会话存储记住窗口 ID，重启后能够复用；失效 ID 会重建。

核心记录及 JSON 备份格式沿用稳定版。在 Chrome 与 360 之间迁移仍需主动导出／导入，不自动读取另一个浏览器的数据。

## 验证范围

- 目标应用：360 极速浏览器 Pro 16.0.1098.0（macOS arm64），内核 Chromium 132。
- 兼容包基础检查、界面回归和真实扩展测试，与 360 的实际 UI 安装验证分开记录。自动化测试通过不代表所有 Chromium 浏览器均已兼容。
- 网页书签、高亮、两种下划线、笔记创建与编辑、删除撤销、默认类型记忆、来源定位、分组搜索和备份均需验证。
- Windows 版 360 和其它内核版本未验证，不作兼容保证。

执行开发验证见 CONTRIBUTING.md；兼容后台专项为 `node test_compat_background.mjs`。确认实际测试结果后再发布预览包，不并入 main。

## 当前验收记录（2026-10-14）

- 26 项基础检查、240 项界面回归、兼容后台专项及 23 项真实扩展检查通过。真实扩展检查运行在隔离的现代 Chrome 中，验证兼容包不依赖原生侧栏的路径；不等同于已通过 360 实测。
- 覆盖管理窗口来源识别、正文定位、关闭、保存、类型记忆、删除撤销、多窗口及重启；窗口越界时自动采用浏览器安排的位置。
- macOS 360 Pro 的实际加载及交互验收尚未完成。此前稳定包因最低内核限制加载失败；兼容包需单独安装验证。
- 此分支不改变 main 或稳定版加载目录。未合并到 main，未发布为稳定 Release。
