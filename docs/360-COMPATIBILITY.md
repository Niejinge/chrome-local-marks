# 360 极速浏览器兼容预览

分支：`compat/360-chromium-132`。独立工作目录、安装目录与包名，保留 `main` 和 v0.7.4 Chrome 稳定版。兼容版最低 Chromium 132，应用版本 0.7.5，版本名称为 0.7.5-360-preview。

## 界面与权限

兼容包不申请 `sidePanel` 权限，点击网页入口或浏览器扩展按钮打开独立标记管理窗口。同一来源窗口重复打开会复用管理窗口；不同浏览器窗口各自保留详情上下文。管理窗口中的“本页”始终读取来源窗口当前网页，避免误读取自身扩展页面。打开窗口不会调整正文窗口大小。

关闭按钮先保存当前编辑，再将来源网页窗口切到前台并关闭管理窗口，方便继续阅读。来源窗口失效时仍可关闭管理窗口。关闭来源窗口会清理对应的管理窗口；关闭管理窗口后可以从网页入口再次打开。后台通过会话存储记住窗口 ID，重启后能够复用；失效 ID 会重建。

核心记录及 JSON 备份格式沿用稳定版。在 Chrome 与 360 之间迁移仍需主动导出／导入，不自动读取另一个浏览器的数据。

## 验证范围

- 目标应用：360 极速浏览器 Pro 16.0.1098.0（macOS arm64），内核 Chromium 132。
- 兼容包基础检查、界面回归和真实扩展测试，与 360 的实际 UI 安装验证分开记录。自动化测试通过不代表所有 Chromium 浏览器均已兼容。
- 网页书签、高亮、两种下划线、笔记创建与编辑、删除撤销、默认类型记忆、来源定位、分组搜索和备份均需验证。
- Windows 版 360 和其它内核版本未验证，不作兼容保证。

执行开发验证见 CONTRIBUTING.md；兼容后台专项为 `node test_compat_background.mjs`。兼容包通过独立的 [v0.7.5-360-preview 预发布版本](https://github.com/Niejinge/chrome-local-marks/releases/tag/v0.7.5-360-preview)分发，不并入 main 或替换稳定下载入口。

## 已知浏览器环境警告

在上述 macOS 360 版本中，扩展页面可能出现 `DOMNodeInsertedIntoDocument` 事件已被移除的警告。这是旧 DOM 变更事件停止触发的提示，[Chrome 官方说明](https://developer.chrome.com/blog/mutation-events-deprecation)建议使用 `MutationObserver`。

2026-10-14 的来源检查结果：

- 源码及安装包的运行时文件均未使用这个事件或其它旧 DOM 变更事件；网页动态恢复使用 `MutationObserver`。
- 错误上下文是管理页面，堆栈为页面第 0 行匿名函数，未指向项目 JavaScript 文件。
- 在同一扩展下临时创建仅有静态标题和段落、不含脚本或事件处理器的 HTML 页面。该页面也产生完全相同的警告，堆栈为临时页面第 0 行匿名函数。
- 插件声明的网页脚本只匹配 HTTP、HTTPS 和 file 地址，不会在该扩展空页面执行。由此排除本项目业务脚本，归为 360 运行环境注入代码的警告；具体浏览器组件未进一步识别。

本次标记、自动保存、定位、删除撤销、分组和 JSON 备份实测均通过，未观察到该警告影响这些流程。临时诊断页面已移除，不包含在安装目录或发布 ZIP 中。保留警告的可见性，不屏蔽浏览器错误，也不恢复已移除的旧事件。若以后出现指向项目 JavaScript 文件的不同错误，应另行排查。
